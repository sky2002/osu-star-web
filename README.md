# osu!mania 4K 星数工具

拖入 `.osu` 或 `.osz`，即可查看 osu!mania 4K 谱面的社区星数、键型分项和最难段落。浏览器在本机处理谱面文件。

[打开在线工具](https://sky2002.github.io/osu-star-web/) · [反馈谱面读数或使用问题](https://github.com/sky2002/osu-star-web/issues/new)

## 怎么用

1. 把谱面、压缩包或曲包文件夹拖进窗口，也可以点击选文件。每个曲包先算第一个 4K 难度，点其他难度的标签就能单独计算。
2. 在谱卡内选择 0.50× 到 2.00× 的倍速，每格相差 0.01×。拖动时可以预览 BPM 和时长，松手后网页计算星数；同一设置的结果可以直接切回。需要看整条倍速曲线时，连续确认两次即可开始，计算途中可以停止。
3. 谱卡会显示总星数、段位和每 10 秒一段的难度。移动准确率曲线上的游标，可以查看打到目标准确率需要的星数，以及它对应的整段和单曲段位。
4. 读数和手感差得较多时，点击“复制读数信息”，把文字连同你的实战感受一起反馈。

网页支持至少有 20 个物件的 osu!mania 4K 谱面。切换模型、倍速或自定义 OD 时，网页会补算当前设置缺少的读数。

## 星数 v4（测试版）

**星数 v4 测试版**是网页的默认版本，冻结日期为 2026-11-23。星数表示平均要多强的玩家才能达到 stable ScoreV1 的 96% 准确率。v4 和 v3 使用同一刻度，v4 的每 10 秒分段也用这把尺。选“对比 v3”可以看两版的星数差和 v3 米段位。模型开关还保留了星数 v3、P1h 旧版和 CNN36 测试版。

在开发测试里，用同一玩家两小时内打的两张谱比较表现，v4 判断哪张更难的判对率是 81.48%，v3 是 80.93%。总星数已检验 NoMod 和 DT，均使用谱面文件 OD。HT、自定义 OD、HR 和 EZ 设置下的读数未经检验。明显滚动变速、带 storyboard 或超出已检验难度范围的谱面会显示读数可靠性提示。

米段位用总星数和 REFORM 整段比较，下一行用 REFORM 官方单曲比较。面段位按 97% ScoreV2 与 LN 6–15 段的谱面读数对照。低于 LN 6 段时，网页按 LN 6–10 段的平均斜率向下估算，并标出“外推”。网页也会列出难度接近的参考谱。

## 六维键型分项（测试版）

分项星数直接显示这类键的峰值难度。失分占比看整首刚好打到 96% 时，丢掉的分有多少落在这类键上。能显示星数的项目排在前面，再按失分占比排序，这样可以先看到哪类键最容易拖低整首准确率。各项可以重叠。

| 分项 | 看什么 |
| --- | --- |
| 叠 | 同一列的连按，例如单列纵连或双押叠。 |
| 乱 | 不同列之间快速移动的单键流，例如楼梯和滚动。 |
| 切 | 双押切和三押切，例如单键和双押交替的长串。 |
| 技 | 节奏变化与协调，例如突然换分音。 |
| 面 | 长条，例如反面长条里夹单点。 |
| 耐力 | 打到容易累的段落时有多难，例如四首连打后半段。它可以和所有键型重叠，所以在最下方单独显示。 |

非变速谱在各个倍速下都可以查看 v4 六维分项。非原速或自定义 OD 下的六维分项未经检验，仅供参考。某类键过少时，网页会把星数显示为“—”。复制读数信息的分项顺序和页面一致。

## 实验性功能和 tosu 插件

打开“更多设置”，可以切换模型、对比 v3，或启用自定义 OD 和旧版米 / 面分项。切回谱面文件 OD 可恢复默认判定。

另有独立的 tosu 插件试用版，选歌时自动显示当前谱面和 Mod 的读数。安装和使用见 [tosu 说明](tosu/README.md) 和 [Releases](https://github.com/sky2002/osu-star-web/releases)。

## 本地预览

在仓库根目录运行以下命令，再打开浏览器中的本地预览。 [本地预览地址](http://127.0.0.1:8790/)

```sh
node tools/serve.mjs 8790
```

页面和段位参照的公开单测可用 `npm run test:unit` 运行。
