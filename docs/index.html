说明

星数是什么意思

平均要多强的玩家，才能在这张谱上打到 96% 的准确率（stable ScoreV1 口径，用谱面文件里的 OD）。数越大越难。

米段位 / 面段位

把这张谱和 REFORM / LN 段位谱用同一模型、同一标准比较，显示它落在哪段及段内位置（如 “Alpha mid（11.0）”）；不代表能通过对应段位。

  • 米段位：用总星数（96% 准确率，ScoreV1）和 REFORM 1st … 10th、Alpha … Eta 的整段（Marathon）读数比较。
  • 面段位：用整张谱按 LN 段位的标准（97% 准确率，ScoreV2）读出的星数，和 LN Dan Courses v2 5th … 15th 的整段读数比较。LN 4 段及以下社区没有公认的标准，所以不用，低于 5 段一律显示“LN5 以下”。
  • 段内方位词按与最近档位锚点的偏差划分（左开右闭）：(−0.5,−0.3]=low、(−0.3,−0.1]=mid/low、(−0.1,+0.1]=mid、(+0.1,+0.3]=mid/high、(+0.3,+0.5]=high；括号内为小数段位位置，保留两位小数。两段读数相差不到 0.05 星（模型重训的波动量级）时合成一档；REFORM 3rd 用同模型 3dan 谱的替代读数，2nd/3rd 可正常分开，LN 14th–15th 仍合并。
  • 长条占物件不到 15% 的谱，面段位变灰，只作参考。总星数标了“不可靠”时，段位也不可靠。
  • HT / DT 下，用这个倍速的读数和 NoMod 段位谱比较。
  • 段位是和四首连起来的整段（Marathon）比的。拿段位里的单曲来算，通常会显得低一点（平均约低 0.3–0.5 段）。
版本

树星数 v1（模型 P1h，冻结日期 2026-10-14）。它和之前本机网页上的“公共星数”刻度不同，难谱上大约高 1 星以上，不要混着比较。

这不是官方星数

这不是 osu! 官方星数，也不会和它一一对应。除 HT / DT 外，不计算其他 mod（HR、EZ、HD 等）。

HT / DT

在上方选 Mod 后，所有谱面会按这个倍速重新计算（算过的会记住，来回切换不用重算）。DT/NC 固定 1.5 倍，HT 固定 0.75 倍；判定窗口按 stable 的 DT / HT 规则换算，OD 仍用谱面文件里的值。

  • DT：模型训练时用过官方成绩库里的 DT 成绩，DT 读数经过和 NoMod 同类的检验。
  • HT：官方成绩库里的 HT 成绩不可靠（多半是练习或试玩），没有用来训练和检验。HT 读数只是“把谱放慢到 0.75 倍”后按同一方法算出来的，仅供参考。
  • 分段曲线的时间轴是变速后的实际时间。附近段位参考谱、米 / 面段位用的仍是各段位谱的 NoMod 读数（谱面按所选倍速算，段位谱不变速）。
什么谱会被拒绝

不是 mania、不是 4K、物件少于 20 个的谱不会出读数。

什么情况会标“不可靠”
  • 有变速：超过 10% 的物件处，滚动速度偏离主速度 10% 以上。训练时排除了这类谱，读数未经检验。
  • 带 storyboard：.osz 里有 .osb 文件，或 .osu 里有 Sprite / Animation 事件。这类可能是观赏或特效谱，读数未经检验。
  • 超出排名谱训练范围：星数高于排名谱最高读数（约 8.9 星），或某项谱面特征超出排名谱的范围。

标了“不可靠”的读数只能当参考，别太当真。

“jack/chordjack 较多”提示

jack（同一列连打）或 chordjack（多键同时连打）占比较高的谱会显示这条提示。长条为主的谱不提示。
