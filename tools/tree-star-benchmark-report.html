发现

映射自洽性成立：16 条 REFORM 段位谱本体 MAE 0.174（1st→1.00、4th–15th 精确命中）——锚点+线性插值这把尺子内部一致。
米侧偏移本质是 jack 梯度，LN 高难端低估由面口径收敛：sky/P1H bias +0.680 → jackBuffed −0.054，总体 MAE 0.871 → 0.546（超过 Sunny 0.617 / Companella 0.625，逼近 Mixed 0.415）。米侧：jack 曲线把 jack MAE 1.335 → 0.609（低 jack 米图 j<0.2 原本 bias 仅 +0.35 段——"整体低估 0.68"主要是 jack 密度越高读得越低）。LN 侧：面口径曲线把 ln≥15 MAE 1.600 → 0.362、ln≥5 MAE 0.780 → 0.454；expected<5 的 15 行（bias −2.63，标注本身有误）按所有者裁决保持原样。剩余短板：jack 箱内 +0.5 段残差（jack180 一个变量解释不完 chordjack 的 pattern 性）。
诚实性边界：两条补正曲线（jack 与 LN）均在本 benchmark 上拟合；留出一半交叉验证显示组内泛化成立（jack holdout bias 收敛到 ±0.05 段内；LN holdout MAE 0.79→0.56 / 0.77→0.46，bias +0.20/−0.26），但跨数据集泛化未验证。jackShare 与 LN 段位读数都与难度相关，曲线可能吸收了部分难度相关的标定误差。Azusa/Roxy/DanOverlay 同样按本 benchmark 调参，此口径一致。
四叶草段只能图一乐（实测确认）：theta/iota/kappa 读数 9.75/9.75/9.68★，不仅全部 unreliable，且不高于 Reform eta（9.786★）——树模型在顶端封顶后，17 段以上完全没有分辨力，PAV 只能合并成一档 pos 18.5。
